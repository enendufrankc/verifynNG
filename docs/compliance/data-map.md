# Data Map

NDPR/NDPA (Nigeria) and UK GDPR data inventory for the Verify platform. One row per data element that could identify a person. Each row's **Retention** column names the E19 retention policy that governs it, written as `` `retention:<policy-name>` `` — that exact token is parsed by a unit test (`apps/api/src/modules/retention/data-map.spec.ts`) against the live policy registry (`GET /v1/retention/policies`), so a typo or a renamed policy here fails CI, not a manual review. A row governed by no policy (kept indefinitely, or never stored) uses `retention:none` instead and is exempt from that check.
