Read this before using the palette

Turquoise cannot be both the brand and a verdict.

The reference palette gives one accent and three signals. An authenticity product needs seven distinguishable verdicts, and the accent has to stay out of all of them — otherwise a consumer learns that “the brand colour” means “genuine”, which is exactly the confusion counterfeiters exploit.

Turquoise is chrome only

Primary buttons, links, focus, selection, active nav. Never a verdict, never a status pill.

#5AE9D7 fill #1CCFB8 text

#5AE9D7 on white is 1.5:1 — it carries dark ink, never light. Turquoise text uses #0E8F7F on light grounds.

Signals are deepened

Green, orange and red keep the reference hue and lose lightness until they clear 4.5:1. The bright originals survive as tints and fills behind dark ink.

One hue added

“Not recognised” needs a hue the reference does not carry. Violet #6B3FA0 sits far from green, orange and red under every common form of colour blindness.

Flagged as an addition. Swap it if the brand has a fifth colour I have not seen.

The verdict family

Four channels carry every verdict. Colour is only one.

Each state is identified by a notch signature, an icon, a band texture and a plain-language label before colour is considered. Strip the colour and all ten remain distinguishable.

Theming

Ivory Glow, as the tenant would actually submit it.

Six keys in, validated, contrast-guarded, resolved into the semantic layer. Anything outside the whitelist is rejected at save time with a named error — dropping it silently would let a tenant believe they had changed something they had not.

tenants/ivory-glow/theme.tokens.json
{
  "$schema": "w3c-design-tokens/1.0",
  "tenant": { "$value": "ivory-glow" },
  "brand": {
    "primary":   { "$type":"color", "$value":"#E3A93C" },
    "secondary": { "$type":"color", "$value":"#5C5140" },
    "surface":   { "$type":"color", "$value":"#F5F1E8" },
    "fg":        { "$type":"color", "$value":"#231C10" }
  },
  "font": {
    "display": { "$type":"fontFamily",
                 "$value":["Playfair Display","Georgia","serif"] },
    "body":    { "$type":"fontFamily",
                 "$value":["Inter","system-ui","sans-serif"] }
  },
  "radius": { "scale": { "$type":"number", "$value":1.5 } },
  "logo": {
    "light": { "$type":"asset", "$value":"ivory-glow/mark.svg" },
    "mono":  { "$type":"asset", "$value":"ivory-glow/mark-mono.svg" }
  }
}

Radius scale is a multiplier on the platform ramp, clamped 0–2. Ivory Glow's 1.5 turns 6/10/16/24 into 9/15/24/36.

Contrast guard · resolution order
1Measure brand.primary against brand.surface. At 4.5:1 or better, use it for text and fills. Done.
2Otherwise darken in OKLCH, reducing L in 0.02 steps at fixed chroma and hue, until it clears. That becomes brand.primary.readable.
3If L hits 0.25 without clearing, fall back to brand.fg and warn in the branding editor.
4Keep the declared value as brand.primary.decorative for rules, large-type fills and the logo field. Never body text or a control label.

Principles

Verdict first

The answer is the first thing painted and the first thing read aloud. Brand and product imagery come after it, or not at all.

Honest, not binary

Ten states, because reality has ten. “Checked before” is history, not a warning. “Not recognised” is an absence of record, not an accusation.

Never a full code

Every rendering is truncated — ivoryglow.2.k1.ABCD… — in the app, the console, the audit log, support tooling and email alike.

Constant trust semantics

A consumer who learns what orange means on one tenant knows what it means on all of them. Hence the verdict family is not themeable.

Low-end first

System fonts until the webfont lands, no blocking imagery above the verdict, no gradient that costs a repaint. Readable at 100 nits and at 1,000.

Dense but calm

The console packs rows tightly and still resolves to one accent, one family and one weight of rule. Density from spacing, not ornament.

AA · 44px · never colour alone

4.5:1 for body, 3:1 for chrome, 44px minimum targets, four redundant channels on every verdict.

The platform recedes

verifynNG appears once per screen, small, as attribution. The tenant owns the surface; the platform owns the meaning.
