# How codes work

Every product carries two codes, not one — and they do different jobs.

## Tier 1 — the QR on the outside of the box

Anyone can scan this, as many times as they like, before or after buying.
Scanning it never changes anything and never claims anything. It tells you:

- the product line and batch,
- "This is a genuine \<brand\> product line — for full unit authentication,
  find the hidden code under the cap / on the scratch-off panel."

Tier 1 exists so browsing customers in a shop can check a product line freely
without the system having to guess whether they're about to buy it.

## Tier 2 — the hidden code inside the pack

This is the one that actually proves _your_ unit is genuine. It's printed
somewhere you can't see until you've opened or peeled the product — under a
scratch-off panel, under a cap, under a seal — specifically so a counterfeiter
can't read and copy it before a real unit is sold.

The first time anyone scans a Tier-2 code, they see: **"You are the first
person to verify this unit — genuine, purchased new."** Every scan after that
is shown honestly, not hidden: _"First verified 12 Aug, Lagos. Verified 3
times since."_ That's not a bug — it's normal for a bottle to get scanned
again by a second-hand buyer, a curious friend, or the same person twice.

## Why you'll sometimes see an amber warning, not a flat yes/no

A single real bottle scanned in Lagos and then again in Nairobi a week later
is either an innocent gift, or a sign the code was copied onto counterfeits.
The system can't always tell which from one scan alone, so it shows the scan
history and a caution level rather than pretending to certainty it doesn't
have.

## The honest limit

A determined counterfeiter _can_ copy one real Tier-2 code onto many fake
units. This system does not claim to make that physically impossible — it
claims to make it _visible_: every copy shows up as unusual scan history
(multiple "first scans," implausible geography, scans before the batch could
have shipped). Detection, not prevention, is the actual product. If a code
you scanned shows a pattern like that, that's the system working, not
failing.
