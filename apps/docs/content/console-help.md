# Console guide: Help

Every module in the console has a **?** link in its page header pointing to
that module's guide, and a **Get help** link that opens this form
pre-filled with the page you were on.

Submitting the form creates a ticket visible to platform support and to you
at **Help → My tickets**, where you'll see their replies. It's the fastest
way to reach a real person if something in the console isn't behaving the
way this documentation says it should.
