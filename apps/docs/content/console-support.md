# Console guide: Support

The Support area (platform staff only) is where you see every tenant, step
into a tenant's console to reproduce a problem, and work tickets that arrive
from the console help form, the public site, or email.

- **Tenants** — every tenant on the platform, with status, plan, and recent
  activity. Click a row to open its detail drawer, or **View as tenant** to
  start an impersonation session.
- **Tickets** — support requests from all three intake channels, unassigned
  first.
- **Canned responses** — reusable reply templates.
- **Impersonation** — history of every impersonation session: who, which
  tenant, mode, reason, duration.

Read `docs/support-impersonation-policy.md` in the repo before using
**View as tenant** for the first time — it covers when read vs. write mode
is appropriate and what's logged. It's an internal support-ops document, not
published here, since this site holds only what a tenant or competitor could
read without harm.
