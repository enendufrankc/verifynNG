# Console guide: Batches

A batch is one minting run — a fixed count of unit codes for one product,
optionally commissioned through an OEM. From here you can:

- **Mint a new batch** (owner only) — pick a product, a count, and
  optionally the OEM that will print it.
- See each batch's status (minting, minted, shipped) and mintedCount vs.
  requested count.
- Open a batch to see its units, deliveries, and print receipts.

If a batch is stuck in `minting` for more than a few minutes, or a mint
request fails outright, that's a [support ticket](/console/help) — include
the batch's idempotency key or the exact error you saw.
