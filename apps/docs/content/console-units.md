# Console guide: Units

A unit is one physical code — the smallest thing this platform tracks. Look
one up by its id (from a batch's unit list, or from an anomaly's detail
page) to see:

- Its current state (active, flagged, decommissioned) and full state
  history.
- Every scan recorded against it — when, roughly where, which tier.

**Flagging** a unit marks it as suspicious without destroying it (an
operator action). **Decommissioning** permanently retires a unit — codes on
recalled or destroyed stock, for example — and is owner-only, since it can't
be undone from the console.

See [How codes work](/docs/codes) for what "first verified" and scan
history actually mean from the consumer's side.
