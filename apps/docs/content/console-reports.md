# Console guide: Reports

A report is a consumer telling you directly that something looked wrong —
submitted from the public verify site when they suspect a fake, separate
from the automatic anomaly signals computed off scan history.

Each report includes the consumer's description, purchase channel, and any
photos they attached, plus (if they scanned one) the redacted code it
relates to — never the raw code, per this platform's rule that a tier-2
code is never displayed or logged in full. Work a report by changing its
status as you investigate, and the consumer sees a plain-language status
update, not your internal notes.

Reports and anomalies often point at the same underlying problem from two
different angles — worth checking both when investigating one product line.
