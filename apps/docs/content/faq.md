# FAQ

**I scanned a code and it says "first verified" by someone else — is my
product fake?**

Not necessarily. If you bought the product second-hand, from a resale
marketplace, or as a gift someone else opened first, an earlier scan is
expected. If you bought it new and sealed and someone else already scanned
it as "first," [contact support]({{VERIFY}}/support) with where and when you bought it
— that pattern is one of the signals that gets a batch investigated.

**The code won't scan at all.**

Most of the time this is a print or lighting issue, not a fake — try a
different phone, better light, and make sure you're not photographing a
reflection off glossy laminate. If it still won't scan, you can also type
the code in manually. If neither works,
[send us the code and a photo]({{CONSOLE}}/help) and we'll check it.

**Why are there two codes on the package?**

See [How codes work](/docs/codes) — the outside QR is for browsing and
product info; the hidden one inside the pack is the one that actually proves
your specific unit is genuine.

**Can someone fake the whole system, not just copy a code?**

The codes themselves are cryptographically random and signed — there's no
pattern to guess, and the raw values are never stored in a way that a
database leak could expose them. See
[How codes work](/docs/codes#the-honest-limit) for what the system does and
doesn't claim to prevent.

**I'm a brand and I want to add codes to a new product.**

That's a console conversation, not a docs one —
[reach out through the console help form]({{CONSOLE}}/help) or your account
contact.
